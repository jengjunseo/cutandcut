# 복사·붙여넣기 / 트랙 삭제 / Shotcut 단축키 · 2026-10-04

## 수정 전 실제 재현

- Chrome에서 제목 클립을 드래그하고 포인터 캡처를 해제한 뒤 다른 위치에서 마우스를 놓았다. 트랙 휴지통을 클릭해도 종료되지 않은 RAF가 이전 프로젝트 draft를 다시 그려 트랙/클립이 돌아왔다. 자동 저장한 모델과 화면이 달라지는 경로다. 회귀 검사에서 클립 0개 기대에 1개가 남았다.
- 한글 자판의 key=ㅊ/code=KeyC, key=ㅍ/code=KeyV를 전달하면 복사·붙여넣기 분기가 동작하지 않았다. 클립 2개 기대에 1개만 남았다. 편집 키가 event.key의 영문만 비교했다.
- 변경하지 않은 속성 숫자 필드에서 포커스를 옮기고 트랙 삭제하는 경우는 정상으로 확인했다. 사용자의 모든 환경을 동일한 원인으로 단정하지 않는다.

## 수정

Timeline의 이동·트림·박스 선택·재생헤드 제스처가 lostpointercapture, window blur, 프로젝트 전환 및 컴포넌트 해제에서 정리되게 했다. RAF·리스너·캡처·draft를 해제하며, 다음 제스처는 이전 제스처를 먼저 취소한다. 이동 완료 후 발생하는 클릭이 선택을 지우지 않도록 했다. 미리보기 변형에도 같은 종료 조건과 편집 키 중단을 적용했다. 취소가 오래된 프로젝트를 commit하지 않는다.

문자 키는 물리 code로 판정하며 문자 입력과 IME 중에는 단축키를 차단한다. 복사 버퍼를 UI 상태로 관리해 붙여넣기 버튼 활성 상태와 실제 내용이 일치한다. 새로 붙인 클립을 선택하고, 실패 이유를 안내하며, 삭제된 복사 원본 트랙은 호환 트랙으로 재생성한다. 트랙 휴지통과 단축키 삭제는 공통 순수 모델을 사용하고 링크·그룹의 잠금을 함께 검사한다. 활성 트랙이 삭제되면 존재하는 트랙으로 전환한다.

실제 MP4 입력의 2.005초 길이에서 컷 후 남은 길이가 1.005초가 됐을 때 End의 프레임 반올림이 1초로 이동하는 경로도 확인했다. 실제 끝으로 요청한 탐색은 정확한 정수 끝 시간을 사용해 마지막 수 ms 안에 삽입을 시도하는 일을 방지한다. 일반 탐색은 기존 프레임 격자를 사용한다.

## 단축키 정책

[Shotcut 공식 단축키](https://shotcut.org/howtos/keyboard-shortcuts/)를 2026-10-04에 확인했다. 실행 키와 도움말 표는 src/shortcuts.ts를 기준으로 관리한다. S 분할, Shift+S 전체 트랙 분할, X 리플 삭제, Z/Delete 일반 삭제, C 복사, Ctrl/Cmd+X 잘라내기, V 삽입, A 끝에 추가, B 덮어쓰기, R 선택 교체 및 대응되는 트랙·탐색·저장·출력 키를 연결했다. Ctrl/Cmd+B 분할은 기존 사용자의 보조 키로 유지한다.

- 영상·오디오가 포함된 삽입/리플 삭제: CyanCut의 기존 동기화 정책에 맞춰 **전체 트랙**을 대상으로 한다. 잠긴 연결·그룹 또는 이동 대상은 부분 수정하지 않는다. 자막·텍스트만 복사한 기본 붙여넣기는 아래 후속 수정에 따라 비파괴 오버레이 배치를 사용한다.

### 자막 붙여넣기 회귀 후속 수정

처음 Shotcut 삽입을 구현할 때 텍스트에도 전체 트랙 시간 삽입을 적용해, 자막 붙여넣기가 재생헤드 아래 영상·오디오와 기존 자막까지 분할하고 뒤쪽을 이동시키는 회귀를 만들었다. 사용자 제보 뒤 새 단위 테스트 3개에서 이 경로를 확인했다. 자막·텍스트만 복사한 기본 붙여넣기는 기존 클립을 그대로 유지하는 오버레이로 수정했다. 한 트랙의 텍스트는 기존 `freeLayer` 배치 규칙을 재사용해 겹치지 않는 레이어에 놓는다. V, Ctrl/Cmd+V, 붙여넣기 버튼과 삽입 메뉴가 같은 규칙을 사용한다. 영상·오디오가 포함된 삽입, 명시적 덮어쓰기·교체와 리플 삭제는 기존 규칙을 유지한다. 이미 저장된 잘못된 편집을 추측해 자동 복구하지 않는다.

- 덮어쓰기: 대상 트랙과 연결·그룹 파트너의 겹치는 구간을 자른다. 교체는 선택한 연결·그룹을 제거한 자리에 복사본을 배치하며 뒤쪽을 당기지 않는다. 각 작업은 한 undo 단위다.
- Ctrl/Cmd+D는 Shotcut처럼 선택 해제이며 기존 복제는 Ctrl/Cmd+Shift+D로 옮겼다. 스냅은 Ctrl/Cmd+P이고 Alt 드래그는 일시 해제다. I/O는 타임라인 트림과 미리보기 구간 지정으로 포커스에 따라 구분한다.
- 이 앱에는 Source 플레이어가 없어 A/V/B/R는 복사한 타임라인 클립을 사용한다. 복사 버퍼는 현재 프로젝트 내부에 있고 프로젝트 전환 시 초기화한다. OS 클립보드 권한이나 미디어 업로드를 요구하지 않는다.
- 필터·키프레임·마커·프록시·작업 목록·리플 모드와 고급 리플 트림 등 없는 기능의 키를 실행 기능으로 표시하지 않는다. Ctrl/Cmd+N·W·Q·T와 일부 패널 키는 브라우저와 충돌하므로 점유하지 않는다. Ctrl/Cmd+2/3/4/5/9는 현재 패널에 대응한다. macOS 기기 실제 검증은 미완료다.
- 입력·IME, 대화상자와 열린 메뉴에서는 편집 키를 적용하지 않는다. 메뉴는 방향키·Enter·Escape로 조작하고 복사/붙여넣기/삭제/배치 방식은 버튼으로도 사용할 수 있다. Shift+←/→ 10프레임, [/] 트림은 기존 확장 키로 유지한다.

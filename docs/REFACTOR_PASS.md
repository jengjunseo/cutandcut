## 보류 판단

- App 1,725행, Timeline 890행, Inspector 731행: 크지만 단순 파일 분할은 책임·데이터 흐름을 개선하지 않는다. 프로젝트 전환/비동기 작업을 한 번에 새 상태 관리로 옮기는 변경은 현재 회귀 위험이 높다.
- CSS 2,860행에 감사 후 override가 쌓였다. cascade/반응형 순서를 대규모 재배치하면 UX 보존을 입증할 비용이 크다. 이번에는 스타일 변경하지 않는다.
- Worker 메시지 전체의 새 RPC 추상화, 전역 상태 라이브러리, 과도한 memo/cache는 추가하지 않는다. 내부 메시지 타입과 오류 경로만 필요한 만큼 정리한다.
- 프레임별 layers 정렬과 샘플별 비동기 믹싱은 성능 측정 후보다. 실제 병목 프로파일이 확보되지 않아 추측 최적화를 수행하지 않는다. 기존 History 벤치마크 결과를 앱 전체 지연 개선으로 확대 해석하지 않는다.
- 모든 브라우저·코덱·대용량 입력에 버그가 없다는 보장은 하지 않는다. 아래 결과는 실행한 검증 범위만 의미한다.

## 변경 및 검증 결과

- **책임과 중복:** 화면비 계산을 기존 순수 geometry로 옮겨 출력 UI의 Inspector 의존성을 제거했다. 활성 트랙 규칙은 model.activeTracks에서 공유하며 렌더·오디오·출력 사전 검사가 같은 solo/숨김/음소거 정책을 쓴다. 영상/오디오 출력의 PCM 추가·타임스탬프·close 루프를 한 함수로 통합했다. 이름 입력의 IME/blur commit, 대화상자 포커스 trap, undo/redo 상태 적용과 Worker 종료 경로도 공통화했다.
- **실제 오류:** 잠긴 연결 구성원을 제외한 부분 분할/배속 변경과 미리보기 변형을 차단했다. 한 프레임 미만의 분할이 normalize에 의해 겹치는 클립으로 늘어나지 않게 했다. 1920×1920 사용자 캔버스의 비율 변경은 기존 크기 상한을 지켜 저장·복구된다. Asset/TextStyle/트랙·소스 호환성 검증을 보완하되 기존 optional 필드는 유지했다.
- **실패 복구:** 캐시 등록 전 분석/이미지 실패 시 Input/ImageBitmap을 해제하고, waveform/출력 AudioSample 및 캔버스 상태를 finally에서 정리한다. Worker 생성·postMessage 동기 실패가 기존 오류 화면으로 전달되고 내보내기를 재시도할 수 있다. 예외 없이 실제 WAV 재출력까지 검사했다.
- **복잡도:** 읽지 않는 revision·timelineFocused·dragging 상태, 불필요 import와 setter wrapper, 잘못 좁혀진 타입 cast를 제거했다. 새 패키지·상태 라이브러리·소스 파일은 추가하지 않았다. 테스트와 검증 방어 코드는 늘지만 정책을 유지해야 하는 위치는 줄었다. 큰 컴포넌트를 기계적으로 분할하지 않았다.
- **성능:** 불필요한 상태 갱신과 changeSpeed의 이중 clone을 제거했다. 장면 전환 캐시 실패는 실제 재현으로 수정했으며 캐시 한도는 12개로 유지한다. 전체 지연/메모리 개선 수치는 측정하지 않았으므로 속도 향상율을 주장하지 않는다.
- **UX 보존:** 스타일 변경 없음. CSS 번들 `index-BJgx1cl9.css`는 이전 배포와 같다. 한국어 UI, 키보드·IME, 편집/저장/출력 정책과 기존 성공 흐름을 유지한다.

검증은 Windows / Chrome 154.0.8037.93 / Node.js 24.12.0에서 수행했다. 수정 전 단위 28개, 새 회귀 검사는 초기 13개 실패와 이후 캐시 실패를 확인했다. 수정 후 단위 **47개**, TypeScript strict 및 unused 검사, 프로덕션 빌드 **5.08초**, Prettier와 git diff check가 통과했다. 전체 통합 **31개**가 통과했고 운영 URL 검사 1개는 별도 실행한다. 마지막 전환 콜백 수정 후의 집중 검사 결과와 운영 배포 결과는 [VERIFICATION.md](VERIFICATION.md)에 기록한다.

전체 통합에는 실제 MP4/WAV/PNG, 한글 합성, 링크 분할·트림·배치·전환·undo/redo, 가로/세로 MP4/WebM/WAV/MP3 파일 분석, 1080p·가변 FPS, AAC 대체, 모듈 실패와 WAV 유지, 저장 실패·복구·프로젝트 전환, 속도/음정 유지, 터치 크기·키보드 검사 등이 포함된다. 다른 OS/브라우저, 장시간 대용량, 스크린리더와 정밀 청취 검증은 추가 대상이다. 확인되지 않은 버그까지 모두 제거했다고 주장하지 않는다.

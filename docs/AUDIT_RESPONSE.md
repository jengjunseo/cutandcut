# 2026-10-03 감사 후 개선

사용자 제공 `cutandcut_audit.html`의 관찰과 완료 기준을 제품 개선 근거로 사용했다. 기존의 밝은 회백색·시안·중립 미리보기와 다층 편집 구조를 유지했다. 이 문서는 구현 범위를 설명하며 실제 수치는 [VERIFICATION.md](VERIFICATION.md)와 `results/`를 참조한다.

## 감사 지적 처리

| 지적 | 구현한 결과 |
|---|---|
| 9:16 표시 크기 0×0 | ResizeObserver의 사용 가능한 너비·높이에서 비율을 유지하는 두 크기를 명시적으로 계산한다. CSS 크기 컨테이너의 자동 높이 순환을 제거했다. |
| MP4 지원을 완성 직전에 알게 됨 | 편집 전 보관함에서 현재 해상도/FPS의 인코더를 검사한다. 네이티브 AAC가 없으면 로컬 WASM AAC로 MP4를 출력한다. H.264 자체가 없으면 이를 알리고 WebM을 안내한다. |
| 가져오기가 삽입까지 수행 | 기본은 보관함만 가져오기. 선택 미디어 순차 배치와 명시적인 가져오기+삽입 옵션을 제공한다. |
| 이미지·텍스트가 같은 트랙에서 겹침 | 빈 상위 레이어를 재사용하거나 새 레이어를 만든다. 의도적인 동일 트랙 겹침은 클립에 '중첩'을 표시한다. |
| 22px 트랙 버튼 | 데스크톱 최소 32×32px, 터치 포인터 최소 44×44px. 컨트롤 줄에 맞게 트랙 높이를 늘렸다. |
| 10~11px 주요 설명 | 저장 제한·원본 제외·오류·출력 지원 설명을 12~13px로 늘렸다. |
| 짧은 프로젝트가 28초 이상에 표시 | 첫 클립/배치의 길이와 화면 너비로 확대율을 맞춘다. 전체 보기 버튼도 제공한다. |
| 잠긴 선택의 툴바가 활성처럼 보임 | 링크·그룹에 잠긴 트랙이 있으면 분할·복제·삭제·리플을 비활성화하고 속성에서 이유를 알린다. |
| 품질 선택 접근성 누락 | 네이티브 radio와 이름 있는 radiogroup의 checked 상태를 사용한다. |
| 출력 설정 변경을 위해 돌아가야 함 | 출력 요약의 설정 변경에서 비율·해상도·FPS를 바로 수정한다. 프로젝트 캔버스에도 적용한다. |
| 세로 결과가 가로 플레이어 안에 작음 | 실제 캔버스 비율의 플레이어와 확대 버튼을 제공한다. |
| 분할 도구 안내 불일치 | '클릭한 위치에서 분할'로 실제 동작과 안내를 맞췄다. |
| 분석·손상 파일 오류 확인 어려움 | 취소·파일별 오류 목록·재시도. 오류/취소 후 기존 프로젝트를 보존한다. |

| 타임라인 | 순차 삽입, 박스 선택, 그룹/해제, 빈 구간 제거, 리플 영향 안내 | 그룹과 영상/원본 오디오 링크는 구분한다. 빈 구간 제거는 전체 트랙의 시간을 함께 당긴다. |
| 연결 | 분리된 같은 원본의 영상·오디오 재연결, 트랙 단독 재생 | 원본 ID·시작·길이·원본 시작·속도가 같은 쌍만 연결. 단독 재생은 시각/오디오 종류별로 적용되며 출력에도 반영. |
| 자막 | 내용·시작·끝 목록, 전체 스타일 적용, SRT/VTT 입출력 | SRT/VTT의 위치·스타일·복잡한 markup은 보존하지 않는 plain-text 경로. |
| 속도·정지 | 0.5–2배, 음정 유지 선택, 합성 화면 PNG/이미지 클립 | 원본 구간을 유지하며 영상·오디오 길이를 함께 변경. 뒤 클립은 제자리에 있으므로 빈틈/중첩을 확인한다. |
| 오디오 | 실시간 피크, 전체 믹스 검사·피크 정규화, 출력 클리핑 안내 | 48kHz 블록 믹싱/WSOLA. 최대 마스터 볼륨 400%, LUFS 정규화 아님. |
| 구도 | 시각 크롭·위치·크기 핸들, 숫자 크롭, 중앙 정렬·반전·안전 영역 | 회전한 클립의 크롭은 숫자로 조절. 안전 가이드는 출력하지 않음. |
| 프로젝트 | 최근 목록·복제·복구 지점·JSON 백업·사용량 | 복제는 같은 로컬 원본 참조. 원본 정리는 모든 저장 프로젝트를 보호. |
| 출력 | 전체/I/O 구간, 예상 크기, 누락/공백/중첩/큰 텍스트 검사 | 원본의 절대 시각을 읽고 출력 시각은 0부터 계산. 텍스트 잘림은 근사 검사. |
| 미리보기 | 100/50/25% 품질, 취소 가능한 분석 | 결과 해상도 유지. 실제 프록시 파일 생성과는 구분. |

## 추가로 발견해 수정한 결함

- 낮은 미리보기 품질이나 홀수 너비에서 CanvasSink에 소수 픽셀 너비를 전달하던 문제를 정수로 제한했다.
- 빠른 박스 선택은 pointerup 좌표를 마지막으로 다시 계산해 선택한다. 고정 눈금과 트랙 스크롤의 좌표도 구분한다.
- 늘어난 미리보기 도구가 모바일의 상단 탭을 가리던 문제를 자동 헤더 높이로 수정했다.
- 새 프로젝트 저장소는 IndexedDB transaction complete 후 성공을 표시하고 이전 버전의 원본을 보존한다. 다른 열린 탭이 업그레이드를 막으면 원인과 복구 방법을 설명한다.

## 남은 범위

기본 색 보정·키프레임·실제 저해상도 프록시·사용자 단축키·최근 프로젝트 삭제는 구현하지 않았다. 장시간/4K·모바일 OS 실기기·다른 브라우저·다양한 촬영본의 배속 음정/위상·정밀 오디오 동기화는 별도 검증이 필요하다. 기존 출력 제한은 5분·예상 256MB·최대 한 변 1920px이며 I/O 구간이 5분 이내면 더 긴 프로젝트의 일부를 출력할 수 있다.

AAC 대체는 **오디오 인코더 부족**을 보완한다. 모든 브라우저의 H.264 영상 인코딩까지 보완했다고 표시하지 않는다. 엔진·라이선스·소스 위치와 재현 빌드 한계는 [NOTICE](../public/licenses/NOTICE.txt)에 기록했다.
